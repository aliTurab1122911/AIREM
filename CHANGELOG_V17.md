# AIREM v17 Changelog

## Formatting & Caption Studio

- Added a Word-style document canvas beside all formatting controls.
- Added immediate live updates without regenerating the DOCX.
- Added Original and Live formatted comparison modes.
- Added zoom control and Fit width.
- Added preview rendering for paragraphs, lists, headings, captions and tables.
- Added live page-size, orientation, margin and page-border simulation.
- Added live header, footer and page-number simulation.
- Added live table font, border, header and supported table-style simulation.
- Added caption SEQ-field indicators and front-field placeholders for TOC, List of Figures and List of Tables.
- Formatting jobs now persist a browser-renderable document preview inventory.
- Existing direct run fonts, sizes and colours are normalized to the selected studio typography so the generated DOCX aligns with the preview.

## Compatibility

- Retains unlimited user-triggered rewrite cycles.
- Retains Detection Engine V3 and Detection Studio.
- Retains pasted-text rewriting and detection comparisons.
- Retains visual non-contiguous DOCX range selection and partial reinsertion.
